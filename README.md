Brief → Script — власний веб-інструмент для генерації скриптів під короткі відеоформати. На вході — бренд, ключове повідомлення й стиль криейтора; на виході — таймкодований скрипт (hook → body → proof → CTA) з підказками on-screen тексту, кепшном і хештегами. Три режими роботи: одиночна генерація, пакетна (кілька криейторів за один прохід) і пресети — для блогерів, з якими працюєш регулярно, стиль зберігається один раз і більше не вводиться вручну. Працює через власний бекенд (Cloudflare Worker + Claude API) з автоматичним відкатом на локальні шаблони, якщо AI недоступний.
